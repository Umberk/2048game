# 2048游戏 - Web版本

## 📝 说明

这是2048游戏的Web网页版本，使用HTML5、CSS3和JavaScript开发，具有现代化的UI设计和流畅的动画效果。

## 🌟 特性

- ✅ 精美的现代化UI设计
- ✅ 流畅的动画效果
- ✅ 响应式布局（支持移动端）
- ✅ 本地排行榜（LocalStorage）
- ✅ 最高分记录
- ✅ 支持键盘和触摸操作
- ✅ 渐变背景效果

## 🗂️ 文件结构

```
Web版本/
├── index.html          # 主页面
├── style.css           # 样式文件
├── game.js             # 游戏逻辑
└── README.md           # 本文件
```

## 🎮 本地运行

直接用浏览器打开 `index.html` 文件即可开始游戏。

## 🔧 技术栈

- **HTML5**: 页面结构
- **CSS3**: 样式和动画
- **JavaScript (ES6+)**: 游戏逻辑
- **LocalStorage**: 数据持久化

## 🎮 游戏控制

- **键盘方向键**: ↑ ↓ ← →
- **WASD键**: W A S D
- **目标**: 合成2048方块

## 📱 浏览器支持

- ✅ Chrome 60+
- ✅ Firefox 60+
- ✅ Safari 12+
- ✅ Edge 79+
- ✅ 移动端浏览器

## 🔍 核心功能

### 游戏逻辑

- 面向对象设计（ES6 Class）
- 四向移动和合并算法
- 胜利/失败检测

### UI效果

- CSS Grid布局
- 平滑过渡动画
- 响应式设计
- 渐变背景

### 数据存储

- LocalStorage保存分数
- 排行榜排序显示
- 最高分记录

## 📊 数据存储格式

```javascript
// LocalStorage数据格式
{
  "game2048_scores": [
    {
      "username": "Alice",
      "score": 2048,
      "date": "2023-07-10T12:00:00.000Z"
    }
  ],
  "game2048_best": 2048
}
```

## 🎨 自定义配置

你可以在 `style.css` 中修改：

- 颜色主题
- 方块大小
- 动画效果
- 背景渐变

你可以在 `game.js` 中修改：

- 游戏规则
- 初始方块数量
- 胜利条件（默认2048）

## 📞 技术支持

如果部署过程中遇到问题，可以：

1. 查看浏览器控制台错误信息
2. 确认文件路径正确
3. 检查服务器配置（如果使用服务器）
4. 确保所有文件都已上传
