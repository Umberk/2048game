# 2048游戏 - Web版本

## 📝 说明

这是2048游戏的Web网页版本，使用HTML5、CSS3和JavaScript开发，具有现代化的UI设计和流畅的动画效果。

## 🌟 特性

- ✅ 精美的现代化UI设计
- ✅ 流畅的动画效果
- ✅ 响应式布局（支持移动端）
- ✅ 本地排行榜（LocalStorage）
- ✅ 最高分记录
- ✅ 支持键盘和触摸操作
- ✅ 渐变背景效果

## 🗂️ 文件结构

```
Web版本/
├── index.html          # 主页面
├── style.css           # 样式文件
├── game.js             # 游戏逻辑
└── README.md           # 本文件
```

## 🎮 本地运行

直接用浏览器打开 `index.html` 文件即可开始游戏。
